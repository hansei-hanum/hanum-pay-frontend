# hanum

한세어울림의 마당의 결제 시스템 한움페이입니다.

## commands

```bash
$ git clone https://github.com/hansei-hanum/hanum-pay-frontend.git
$ cd hanum-pay-frontend
$ pnpm install

# development
$ pnpm run dev

# production
$ pnpm run build
$ pnpm run preview
```
